# Module 1 — Python & Data Science Fundamentals

## Overview

Module 1 establishes the foundational programming and analytical skills required for Data Science.

The module progresses from basic Python programming concepts to practical exercises involving data structures, control flow, functions, file handling, and introductory Data Science concepts.

---

## Learning Objectives

By the end of this module, I aim to be able to:

* Write basic Python programs
* Work with variables and different data types
* Manipulate strings and collections
* Use lists and dictionaries effectively
* Apply conditional statements and loops
* Create reusable functions
* Read and write files
* Perform basic data processing
* Explain the Data Science lifecycle
* Apply programming concepts to practical problems

## Notebooks

### 01 — Python Fundamentals

Introduction to Python syntax, variables, data types, operators, strings, user input, and basic programming concepts.

**File:** `01_python_fundamentals.ipynb`

### 02 — Data Structures

Working with lists, tuples, dictionaries, sets, and basic data manipulation.

**File:** `02_data_structures.ipynb`

### 03 — Control Flow & Functions

Using conditional statements, loops, functions, parameters, and return values to solve programming problems.

**File:** `03_control_flow_functions.ipynb`

### 04 — File Handling

Reading, writing, and processing data stored in files, including CSV data.

**File:** `04_file_handling.ipynb`

### 05 — Data Science Fundamentals

Introduction to Data Science concepts, the Data Science lifecycle, real-world applications, and the role of Python in data analysis.

**File:** `05_data_science_fundamentals.ipynb`
